ABOUT MESHCHAT

How it works

MeshChat is an offline-first messenger concept. Devices communicate directly over local wireless transports. No central message server is used. Messages are stored locally, and encryption helpers are provided for peer sessions.

This initial build does not claim that all transport, relay, group, or file-transfer features are complete.
